# ULTIMATE FIGMA AI PROMPT FOR KARIAKOO SDA CHURCH WEBSITE

Design and generate a **world-class, enterprise-grade, modern, responsive, secure, AI-powered church website and web application** for **Kariakoo Seventh-day Adventist Church (Kariakoo SDA Church), Dar es Salaam, Tanzania**.

The website must be one of the most advanced church websites in Africa, combining ministry, worship, youth programs, digital services, administration, communication, donations, events, media, learning resources, and community engagement in a single platform.

* Modern Premium UI/UX
* Responsive on Mobile, Tablet, Laptop, Desktop and Smart TV
* Fast Loading
* SEO Optimized
* Offline Asset Support
* Accessibility Standards (WCAG)
* Dark Mode and Light Mode
* English / Swahili Language Toggle
* Smooth Animations
* Professional Typography
* Glassmorphism + Modern Church Design
* High Quality Hero Sections
* Modern Card Layouts
* Elegant Hover Effects
* Premium Dashboard Experience

Color Palette:

* Deep Navy Blue
* Royal Blue

* White

* Elegant Gradients

The design must feel better than most church websites in Africa and comparable to premium international ministry websites.
